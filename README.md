# ☕ Coffee Shop Sales Dashboard

A bilingual (TH/EN) **decision-support dashboard** for a coffee shop that turns live Google
Sheets sales data into KPIs, charts, full **DSS statistics**, and AI-written recommendations —
all in a single static page with no build step.

🔗 **Live demo:** https://songpolr.github.io/coffee-dashboard/ (GitHub Pages)

---

## ✨ Features

- **Live KPIs** — total sales, cups sold, unique customers, average price/cup, average spend/customer.
- **Charts** (Recharts) — sales by menu, hot vs iced, dine-in vs takeaway, and a price-mix distribution.
- **Statistical analysis (DSS)** over spend-per-customer and the whole store:
  - Descriptive statistics (mean, median, mode, SD, CV, quartiles, IQR, **moment-based skewness**).
  - Spend-per-customer **histogram** with round bin edges.
  - **Frequency distribution** by menu (count / %, proportion, cumulative %).
  - **Chi-square** association test with **Cramér's V**.
  - **Market-basket analysis** (association rules: support / confidence / **lift**).
- **Performance & Recommendations** — a rule-based expert summary of the store's numbers.
- **AI Recommendation** — fresh, plain-language advice generated by **Claude Haiku** from the
  computed statistics (optional; see [AI setup](#-ai-recommendation-optional)).
- **Realtime sync** — updates instantly via Firebase when the source sheet changes, with a
  polling fallback.
- **Bilingual** Thai/English toggle and **dark/light** theme.

## 🧱 Tech stack

Pure **static site** — no bundler, no `npm install` to view it. Everything loads from CDNs and the
JSX is transpiled in the browser by Babel Standalone.

| Layer | Technology |
|---|---|
| UI | React 18 + Recharts (UMD via CDN), Babel Standalone (in-browser JSX) |
| Realtime | Firebase Realtime Database (compat SDK) |
| Data API | Google Apps Script Web App (reads the Google Sheet live) |
| AI (optional) | Firebase Cloud Function → Anthropic Claude Haiku |
| Hosting | GitHub Pages |

## 🔄 Architecture & data flow

```
Google Sheet (source of truth)
      │  edited by the shop
      ▼
Apps Script Web App (/exec)  ──reads the sheet live──▶  JSON { rows, issues, found, maxNo }
      │                                                        ▲
      │ on change, writes /signal                              │ fetch on sync
      ▼                                                        │
Firebase Realtime DB  ──/signal (realtime ping)──▶  Dashboard (static, GitHub Pages)
      ▲                                                        │
      │ admin writes /aiRecs/<hash>                            │ reads /signal + /aiRecs
      │                                                        ▼
Cloud Function (Claude Haiku)  ◀────────POST stats────────  AI Recommendation card
```

- The dashboard **reads only**; the only writers are Apps Script (`/signal`) and the Cloud Function
  (`/aiRecs`). Database rules enforce this.
- If Firebase isn't configured, the page falls back to polling the Apps Script API every 15s.

### Data model

Each sales row returned by the API:

```json
{ "cus": "C001", "p": "ลาเต้", "t": "ice", "k": "to go", "pr": 60, "q": 1 }
```

| Field | Meaning | Example |
|---|---|---|
| `cus` | customer id (groups a basket / bill) | `"C001"` |
| `p` | menu / product | `"เอสเพรสโซ"`, `"อเมริกาโน่"`, `"ลาเต้"`, `"คาปูชิโน่"`, `"มอคค่า"` |
| `t` | temperature | `"hot"` \| `"ice"` |
| `k` | service type | `"for here"` \| `"to go"` |
| `pr` | unit price (THB) | `50` \| `60` \| `70` |
| `q` | quantity (cups) | `1` |

## 🚀 Run locally

It's a static site — serve the folder with any static server:

```bash
# from the project root
python3 -m http.server 5173
# open http://127.0.0.1:5173/index.html
```

The dashboard ships with embedded sample data, so it renders immediately. Configure `config.js`
(below) to pull live data and enable realtime sync.

## ⚙️ Configuration

All settings live in **`config.js`** — these are **public identifiers, not secrets** (the only real
secret, the Firebase DB write key, stays in Apps Script's Script Properties):

```js
window.APP_CONFIG = {
  "apiUrl":   "https://script.google.com/macros/s/…/exec",  // Apps Script Web App
  "aiFnUrl":  "",                                           // AI Cloud Function ("" = hide AI card)
  "sheetUrl": "https://docs.google.com/spreadsheets/…",     // "Open Sheet" button
  "firebase": { /* Firebase web config — protection is via DB rules */ }
};
```

### Source data API (Apps Script)

`apps-script/Code.gs` is a Google Apps Script Web App that reads the bound Google Sheet live and
returns the rows as JSON. Deploy it as **Web app** (Execute as *Me*, access *Anyone*), then paste
the `/exec` URL into `config.js` → `apiUrl`. Full instructions are in the header comment of
`Code.gs`.

### Realtime sync (Firebase)

Apps Script writes a `/signal` node to Firebase whenever the sheet changes; the dashboard listens
and re-syncs instantly. Deploy the rules with:

```bash
firebase deploy --only database
```

## 🤖 AI Recommendation (optional)

A separate **Firebase Cloud Function** holds the Anthropic API key server-side, calls **Claude
Haiku** with the *already-computed* statistics, and caches the result in Realtime DB for the client
to read. It's rate-limited to one generation every 3 minutes.

See **[AI_RECOMMENDATION_SETUP.md](AI_RECOMMENDATION_SETUP.md)** for the full deploy walkthrough
(requires the Firebase **Blaze** plan). Leave `aiFnUrl` empty to hide the card entirely.

## 📊 DSS methods reference

The statistics are computed client-side in `app.jsx`:

- **Skewness** — moment-based (Fisher–Pearson), equivalent to Excel's `SKEW`.
- **Quantiles** — type-7 interpolation (matches Excel `PERCENTILE.INC`).
- **Chi-square** — p-value via the regularized incomplete gamma function; association strength via
  **Cramér's V**.
- **Market basket** — per-customer baskets → association rules ranked by **lift**.
